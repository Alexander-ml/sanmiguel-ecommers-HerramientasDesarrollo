# 0. Versiones base

| Componente  | Versión recomendada (actual a la fecha) |
| ----------- | --------------------------------------- |
| Java        | 21 (LTS)                                |
| Spring Boot | 4.1.x                                   |
| Node.js     | 20 LTS                                  |
| React       | 19                                      |
| MySQL       | 8.4                                     |

---

## 1. Backend Spring Boot

| Dependencia (Maven)                                                                                                                             | Para qué sirve                                                                                          |
| ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `spring-boot-starter-webmvc`                                                                                                                    | Expone la API REST (Tomcat embebido + Jackson para JSON)                                                |
| `spring-boot-starter-data-jpa`                                                                                                                  | ORM con Hibernate mapea clases Java a tablas                                                            |
| `com.mysql:mysql-connector-j`                                                                                                                   | Driver JDBC de MySQL                                                                                    |
| `spring-boot-starter-flyway` + `org.flywaydb:flyway-mysql`                                                                                      | Migraciones de base de datos versionadas (`V1__crear_productos.sql`, `V2__agregar_stock_minimo.sql`...) |
| `spring-boot-starter-security`                                                                                                                  | Autenticación/autorización, hashing de contraseñas (BCrypt)                                             |
| `io.jsonwebtoken:jjwt-api`, `jjwt-impl`, `jjwt-jackson`                                                                                         | Emitir y validar JWT propios                                                                            |
| `spring-boot-starter-validation`                                                                                                                | Validar los datos que llegan en cada petición (`@NotNull`, `@Email`, `@Min`...)                         |
| `spring-boot-starter-actuator`                                                                                                                  | Health checks y métricas                                                                                |
| `springdoc-openapi-starter-webmvc-ui`                                                                                                           | Genera automáticamente el contrato OpenAPI/Swagger desde el código                                      |
| `org.projectlombok:lombok`                                                                                                                      | Genera getters, setters, constructores automáticamente                                                  |
| `org.mapstruct:mapstruct` + `org.mapstruct:mapstruct-processor` + `org.projectlombok:lombok-mapstruct-binding`                                  | Convierte automáticamente entre Entity (JPA) y DTO (lo que expone la API)                               |
| Un `-test` por cada starter (`spring-boot-starter-webmvc-test`, `spring-boot-starter-data-jpa-test`, `spring-boot-starter-security-test`, etc.) | Pruebas unitarias y de integración de cada módulo                                                       |
| `spring-boot-testcontainers` + `org.testcontainers:testcontainers-mysql` + `org.testcontainers:testcontainers-junit-jupiter`                    | Pruebas de integración contra un MySQL real corriendo en Docker                                         |

## 2. Frontend React

| Dependencia                         | Para qué sirve                                                                                              |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `react` + `react-dom`               | Base de la librería                                                                                         |
| `typescript`                        | Tipado estático                                                                                             |
| `vite`                              | Build tool y servidor de desarrollo                                                                         |
| `react-router`                      | Rutas                                                                                                       |
| `@tanstack/react-query`             | Maneja el **estado de servidor**: trae datos de la API, los cachea, los refresca solo                       |
| `zustand`                           | Maneja el **estado de cliente puro**: carrito abierto/cerrado, usuario logueado en memoria, tema            |
| `axios`                             | Cliente HTTP, con interceptores                                                                             |
| `react-hook-form` + `zod`           | Formularios y su validación                                                                                 |
| `react-bootstrap` + `bootstrap`     | Componentes de interfaz ya armados (botones, modales, formularios, grid) sobre Bootstrap 5                  |
| `openapi-typescript` (o `orval`)    | Genera automáticamente los tipos TypeScript y el cliente HTTP desde el `openapi.yaml` que expone el backend |
| `msw` (Mock Service Worker)         | Simula las respuestas del backend en desarrollo, usando el mismo contrato                                   |
| `vitest` + `@testing-library/react` | Pruebas                                                                                                     |
| `eslint` + `prettier`               | Calidad y formato de código                                                                                 |
